第三章：常见问题
================

如何添加新章节？
----------------

新建一个 ``.rst`` 文件，然后在 :file:`index.rst` 的 ``toctree`` 中登记文件名。

标题层级如何规定？
------------------

一级标题用 ``=``，二级用 ``-``，三级用 ``~``，同级标题必须使用同一个字符。

如何引用其他章节？
------------------

先在目标位置定义标签（如 :ref:`install-deps` 处的 ``.. _install-deps:``），
再用 ``:ref:`install-deps``` 引用。

如何清理构建产物？
------------------

.. code-block:: powershell

   python build.py clean
